# Phase-03: Dynamic QR Code Generator

## Context
We need to generate a Time-Based One-Time Password (TOTP) QR code that refreshes automatically. While we will eventually tie this to the active member subscription logic, we first need to build the standalone generator UI. We will use a dedicated test account (`qrcode@gmail.com` / `qrcode123`) to route directly to this generation screen so we can test it against the scanner we built in Phase-02.

## Scope
- Integrate a new route/role check in the login flow for `qrcode@gmail.com`.
- Create a new `Generator` screen that displays a dynamic QR code.
- Implement an automatic refresh timer (e.g., every 15 seconds) that updates the QR code payload.
- Use a robust QR code generation library.

## Steps

1. **Install QR Code Dependency:**
   - Run `npx expo install react-native-qrcode-svg react-native-svg`.

2. **Update Login Routing:**
   - Modify the login handler: if the email is `qrcode@gmail.com` (password: `qrcode123`), assign the `generator` role and route them to a new `src/app/(generator)/display.tsx` screen.

3. **Build the QR Generator Component:**
   - Create `src/app/(generator)/display.tsx`.
   - Set up state for `qrPayload` and `timeLeft` (countdown timer).
   - Create a function `generatePayload()` that creates a string containing the current user ID (mocked as "test-user-123") and the current Unix timestamp.

4. **Implement the Refresh Interval:**
   - Use a `useEffect` hook to run `generatePayload()` immediately on mount.
   - Set up a `setInterval` to run every 15 seconds: update the `qrPayload` and reset a visual countdown timer so the user knows when the code will refresh.
   - Clear the interval on component unmount.

5. **Render the UI:**
   - Render the `<QRCode>` component from `react-native-qrcode-svg`, passing `qrPayload` as the `value` prop.
   - Add a visual indicator (like a loading bar or text) showing the seconds remaining until the next refresh.
   - Ensure the screen prevents the device from sleeping (optional, using `expo-keep-awake`) if it's meant to stay on screen.
